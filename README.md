# Sistema de Gestión de Licitaciones

Este proyecto es una solución para la administración de ofertas y documentación.

## Tecnologías
* **Backend:** PHP Nativo (Arquitectura MVC).
* **Frontend:** Vue.js 3 & Axios.
* **Base de Datos:** MySQL.
* **Estilos:** Bootstrap 5.
* **Entorno recomendado:** Laragon.

## Instalación y Configuración

1. **Clonar el proyecto:** Extraer el repositorio en la carpeta `C:/laragon/www/`.

2. **Base de Datos:**
   * Script `sistema_licitaciones.sql` abrir desde el gestor MySQL.
  

3. **Acceso al Proyecto:**
   * Si usa Laragon: `http://proyecto-licitaciones.test/`.
